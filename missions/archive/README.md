# Mission archive

Historical `.miz` builds retained for recovery, comparison and regression analysis. Subfolders group them by mission:

- `huey-spot-height-insertion/`
- `northeast-intercept-syria/`
- `syria-base-template/`

These builds have **not** been newly certified as stable or released simply because they are in the archive. Historical filenames and binary content are preserved exactly.

For everyday flying, use `../released/` once a build has passed acceptance testing. For continued development, use `../development/`.
