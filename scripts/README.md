# Scripts

This folder contains reusable scripting support for DCS missions.

- `custom/` — small project-specific Lua modules.
- `mist/` — MIST library files or integration notes.
- `moose/` — MOOSE library files or integration notes.

Record framework versions and script load order in the mission documentation. Do not add a framework unless it provides a clear benefit over Mission Editor triggers or a smaller custom script.
